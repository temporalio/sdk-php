## Patterns Identified

- **Single root cause, multiple symptoms** — `TaskQueueResolver::SHARED_QUEUE_EXCLUSIONS` missing 2 entries caused 5 acceptance failures across Versioning/Fibers/Classic + Versioning/Fibers/Deployment (1 occurrence, 5 downstream symptoms)
- **Worktree base mismatch from misbranched agents** — multiple agents started worktrees at master HEAD instead of fibers HEAD, polluting reviews with unrelated changes (3+ occurrences)
- **Silent Fiber-path bypass via `yield` in Fiber-mirror tests** — `RawValueTest.php`, `ContextTest.php`, `BuiltInPrefixedHandlersTest.php` "passed" Fiber tests that actually ran the Generator path because they still contained `yield`/`\Generator` (3 occurrences)
- **Workflow type / activity prefix name collisions on shared task queue** — 5 separate "Entry with same identifier" worker-boot crashes from Fiber siblings reusing the non-Fiber sibling's wire-level name
- **Debug-call STDOUT pollution corrupting RoadRunner framing** — `file_put_contents` left by killed sub-agents in `Process.php` caused workflow timeouts at 60s+ across `RawValue`/`BinaryProtobuf`/`JsonProtobuf` tests (1 occurrence, ~4 cascading failures)
- **Experimental type leak into stable public API** — `Fibers\Mutex` reaching `WorkflowContextInterface`, `AwaitInput`, `\Temporal\Workflow::await` union types via well-meaning but incorrect signatures (1 architectural pattern)
- **Auto-revert of load-bearing one-liners** — `StackRenderer::$userFrameSeen` reverted twice by review agents who couldn't understand the conditional from the immediate context (2 occurrences)
- **PHPUnit filter regex matching unintended siblings** — `--filter='Versioning.Classic'` matched both Fiber and non-Fiber Classic tests; led to false ordering-bug hypothesis (1 occurrence, hours wasted on wrong hypothesis)

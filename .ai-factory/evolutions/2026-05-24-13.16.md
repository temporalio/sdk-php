## Patterns Identified

- **Trans-script blind spot: alias shadowing in expression position** — `use Temporal\Experiments\Fibers\Workflow;` shadows `Temporal\Workflow\X` for both attribute (`#[Workflow\X]`) AND expression (`Workflow\X::method()`) references; original trans-script handled attribute case but not expression. 3 test files broken (1 occurrence, 4 test methods downstream).
- **Trans-script blind spot: wire-name asymmetry** — injecting `prefix: 'Fibers_'` into `#[ActivityInterface]` changes registered wire name to `<prefix><method>`, but bare-string `Workflow::executeActivity('<name>', ...)` call sites in the same file are not auto-rewritten. 4 tests silently timed out at `RETRY_STATE_TIMEOUT` (4 occurrences).
- **Mechanical yield-removal insufficient for promise combinators** — `Promise::race([X, Workflow::timer(N)])` after yield-removal blocks sequentially because Fibers-facade `Workflow::timer()` returns void and `$stub->getResult()` blocks. Required: switch to `*Promise()`/`*Async()` variants + `FiberHelper::await(Promise::race(...))`. 2 occurrences in 1 file, 2 tests downstream.
- **Global-registry collisions are not limited to workflows/activities** — same collision pattern as workflow-type/activity-prefix uniqueness applies to global constants (`\define`), plugin names (`getName()`), and likely any other process-global registry. Adding `_Fibers` infix solves all of them. 2 global constant occurrences, 1 plugin name occurrence.
- **Typed proxy auto-await is irreversible** — `FiberProxy::__call` always awaits any returned `PromiseInterface`. Original Generator patterns that relied on unawaited promises (`$handle = $wf->run(); yield $wf->signal(...); return yield $handle;`) deadlock under mechanical conversion. No opt-out exists; tests must rewrite to untyped stub with explicit `*Async()` calls. 2 tests stuck on this (`Signal/ChildWorkflow`, `ChildWorkflow/Signal`).
- **`Workflow::async()` scope needs explicit `->join()` in Fibers** — original `yield $scope` join semantic doesn't survive mechanical yield-removal. Introduced `FiberScope` wrapper (`src/Experiments/Fibers/FiberScope.php`) exposing `join()` that does `FiberHelper::await($inner)`. 1 occurrence (`CancelTryCancelTest`), fixed by + 1 line.
